# Support

Need help with FreeTheAI? Start here.

| I want to | Go to |
| --- | --- |
| Read how to use the API and the SDKs | [freetheai.org/docs](https://freetheai.org/docs) and each repository's docs site |
| Set up an app or coding agent | [freetheai.org/setup](https://freetheai.org/setup) |
| Check which models exist | [freetheai.org/models](https://freetheai.org/models) |
| See if the service is up | [freetheai.org/status](https://freetheai.org/status) |
| Ask a question or get help from the community | [Discord](https://discord.gg/secrets) |
| Report a bug in a repository | Open an issue using the bug report form in that repository |
| Request a feature | Open an issue using the feature request form in that repository |
| Report a security problem | Email vibheksoni@engineer.com (see [SECURITY.md](SECURITY.md)) |

When you ask for help with an error, include the **error id**. Every API error has one: it is in the error message, in the response body as `error_id`, and in the `X-Error-ID` header.

Please never post your API key in a public issue or chat. If you think a key was exposed, create a new one on the [API keys page](https://freetheai.org/dashboard/api-keys).
